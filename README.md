## What I've Shipped

### Share Music — [Live on iOS & Android](https://apps.apple.com/us/app/share-music/id6748662306)
A social music-sharing platform that generates universal streaming links across Apple Music, Spotify, Tidal, and Deezer — then lets you share them in real-time conversations with friends.

- Full-stack solo build: iOS (Swift/SwiftUI) + Android (Kotlin/Jetpack Compose)
- Firebase backend: Firestore, Cloud Functions (Node.js), Analytics, Crashlytics
- Real-time social features: DMs, friend graph, now-playing presence, push notifications
- Cross-platform music links across 36 regional storefronts (Apple Music, Spotify, Tidal, Deezer)
- 2-tier subscription model via StoreKit 2 + RevenueCat
- Growth: Python Reddit bot, App Store Optimization across 9 locales

### Hangs — Early Public Beta
An ambient social intelligence app that nudges friend groups when their schedules, interests, and local events align.

- iOS (Swift/SwiftUI) + Firebase backend
- **Firebase AI Logic (Gemini)** integration — AI-powered contextual suggestions
- NudgeEngine: real-time calendar + availability matching system
- Google Places API, SwiftData, per-day time preferences, FCM push notifications
- Invite-only rollout model
